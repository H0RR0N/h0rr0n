Unique Partner Email

Odoo 19 LGPL-3

This module prevents having multiple partners (res.partner) with the same email address in the system. It combines an ORM validation check with a database-level unique constraint on the normalized email value.

Features

  • Unique Email Enforcement — Prevents duplicate emails across all partners
  • Case-Insensitive — Email comparison is case-insensitive (Test@Example.com = test@example.com)
  • Clear Error Messages — Shows which partner already uses the email
  • Empty Email Allowed — Partners without email are not affected
  • Ukrainian Translation — Full module translation to Ukrainian

Configuration

No configuration required. Install the module and the constraint is active immediately.

Note: If existing partners have duplicate emails, you need to resolve those duplicates before or after installing this module. The validation runs on create/write, and the SQL constraint protects the data at the database level as well.
