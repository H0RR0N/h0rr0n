# HR Hospital

Language: [English](README.md) | Українська

Короткий навчальний модуль для Odoo 19 з процесом роботи лікарні.

Містить:
- пацієнтів, лікарів, захворювання, візити
- діагнози та розклади лікарів
- майстри для перепризначення/звітів/перенесення/експорту
- демо-дані для швидкої перевірки
