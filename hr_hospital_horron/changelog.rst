Changelog
=========

19.0.5.0.0 (2026-03-03)
------------------------

**Changes:**

* Added the printable doctor report for module 5 and finalized the doctor kanban flow.
* Localized doctor report labels and added report-specific Ukrainian translations.
* Applied mentor review fixes and aligned the module with Odoo 19 best practices.
* Refined report templates, model logic, utilities, and related views as part of the final cleanup.

19.0.4.0.0 (2026-02-20)
------------------------

**Changes:**

* Upgraded the module from the lesson 3 state to the lesson 4 state.
* Updated patient, visit, diagnosis, doctor, and menu views for the next training stage.
* Expanded Ukrainian translations and refreshed demo data for visits and diagnoses.
* Included the minor follow-up cleanup committed on the same day.

19.0.3.0.0 (2026-02-13)
------------------------

**Changes:**

* Added the abstract person model and extended doctor and patient data structures.
* Added doctor specialities, doctor schedules, medical diagnoses, and patient doctor history.
* Implemented visit workflow constraints, diagnosis approval logic, and new utility wizards.
* Added patient card export, disease reporting, visit rescheduling, and mass reassignment tools.
* Moved wizard XML files into the `wizards/` directory and improved doctor archiving behavior.

19.0.2.0.0 (2026-02-10)
------------------------

**Changes:**

* Improved module documentation and refreshed demo data.
* Added dedicated demo users for doctors and linked doctors to user accounts.
* Expanded demo fixtures for contact persons, diseases, diagnoses, visits, schedules, and doctor history.

19.0.1.0.0 (2026-02-02)

**Changes:**
